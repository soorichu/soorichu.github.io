# Privacy Policy

EinkNote ("we", "our", or "the Service") values your privacy and is committed to protecting your personal information. We strictly comply with applicable privacy laws and the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy). This Privacy Policy explains what information is collected through Google OAuth, how it is used, and how it is protected.


## 1. Information We Collect

EinkNote accesses only the minimum necessary data with the user's explicit consent via Google OAuth authentication.

- **Requested Google API Scopes:**
  - `https://www.googleapis.com/auth/documents`: Permission to view, edit, create, and delete user Google Docs.
  - `https://www.googleapis.com/auth/drive`: Permission to view and manage Google Drive files and documents necessary for exporting notes.


## 2. Purpose of Data Collection and Usage

Any accessed or collected data is used strictly for the following purposes:

[Demo Video & Data Handling Explanation](https://youtu.be/CwwFczbeizQ)

- **Exporting Notes to Google Docs:** To save and sync notes created within the app directly to the user's Google Docs.
- **Core App Functionality:** Unlike standard Android devices, E-ink devices are sensitive to screen refreshes and struggle with resource-heavy applications. EinkNote is designed with a minimal UI and lightweight text editor tailored for E-ink screens, allowing users to write comfortably and export their notes to Google Docs for subsequent editing across their devices.
- **No Unauthorized Access:** Neither the developer nor any third parties have access to the user's Google Cloud storage or Google account. The app requires no sign-up or registration, and no personal user data is ever collected.
- **Customer Support:** Addressing user inquiries and support requests when contacted directly.


## 3. Data Retention, Storage, and Deletion

- **Zero-Storage Policy:** EinkNote does not store, harvest, or retain any personal data on external servers.
- **Local Storage Only:** Notes and application data remain strictly on the user's local device and the user's own Google Cloud/Drive account. No data is transmitted to, stored on, or distributed to any external server.
- **Revoking Access:** Users can revoke EinkNote's access permissions at any time by logging out, uninstalling the app, or managing permissions directly via the [Google Security Settings (Third-party apps)](https://myaccount.google.com/permissions).


## 4. Third-Party Sharing and Disclosure

We do not sell, rent, trade, or share your personal data or Google user data with any third parties under any circumstances, except where strictly required by applicable law or formal legal process.


## 5. Compliance with Google API Services User Data Policy (Limited Use)

EinkNote strictly adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the **Limited Use requirements**:

- Google user data obtained via Google APIs is used solely to provide and improve user-facing features that are prominent in the application’s user interface.
- We do not use or transfer Google user data for serving advertisements, including personalized, re-targeted, or interest-based advertising.
- We do not sell Google user data to any third party.
- We do not allow humans to read user data unless we have obtained your explicit consent, it is necessary for security purposes, or it is required to comply with applicable laws.
- We do not use Google user data to train or fine-tune general artificial intelligence (AI) and/or machine learning (ML) models.
